FILE 01DETAILED LESSON PLAN

System Unit Assembly & Disassembly

This lesson plan addresses the careful and systematic handling of system-unit components. In a computer hardware lesson, learners benefit from understanding the parts of a computer as well as the correct sequence and precautions involved when assembling and disassembling a unit.

The plan provides a structure for instruction and hands-on practice, connecting technical knowledge with procedures that can be demonstrated, observed, and assessed. It reflects the need to give students clear expectations before they perform practical tasks.

LEARNING FOCUS

Component recognition, procedures, safe handling, and practical understanding.

INSTRUCTIONAL VALUE

Combining explanation with guided performance to make technical skills more accessible.

FILE 02FINAL DEMONSTRATION LESSON PLAN

Creating and Formatting a Structured Document

This lesson plan focuses on using Microsoft Word to create a structured, readable document. The topic connects digital literacy with practical communication skills, as students work with tools and formatting features needed to organize written material clearly.

It highlights the importance of guiding students through a digital task in a meaningful sequence, with clear instructions, opportunities for application, and criteria for checking the finished document.

LEARNING FOCUS

Document organization, formatting tools, and the creation of a structured output.

INSTRUCTIONAL VALUE

Moving from demonstration to practice while reinforcing consistency, accuracy, and readability.

FILE 03INSTRUCTIONAL PRESENTATION

Final Demonstration Presentation

The final demonstration presentation accompanies the structured-document lesson. It helps organize the flow of discussion and activities while giving learners a consistent reference as they work through formatting concepts and classroom tasks.

As an instructional support material, the presentation illustrates how visual organization can help a teacher communicate key points, manage transitions between activities, and reinforce lesson objectives.

LEARNING FOCUS

Instructional sequencing, guided examples, and reinforcement of document-formatting concepts.

INSTRUCTIONAL VALUE

Making teaching points easier to follow and supporting organized classroom delivery.

REFLECTION ON PREPARATION

These outputs remind me that the quality of teaching depends not only on knowledge of the topic but also on the ability to organize learning experiences. Objectives, materials, practice, and assessment should work together to support understanding.
