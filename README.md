# Angel Marcelo Vidad | Field Study Portfolio

A completely redesigned, text-only academic portfolio with a charcoal left-hand table of contents and separate navigation views. This version does not reuse the previous sage-and-ivory one-page theme, imagery, photo gallery, cards, or hero layout.

## Main sections

1. Overview — academic profile and navigation
2. Field Study — documented INCAT and MMSU Laboratory High School placements
3. Teaching Work — selected lesson plans and presentation
4. Documents — searchable, filterable index of 27 original Drive files

## Deployment

Static HTML, CSS and JavaScript. No build system or external fonts required.
Publish with GitHub Pages from `main` / repository root.

The previous `assets/` directory is no longer referenced by the website; it remains untouched in repository history and storage.
