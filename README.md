# Angel Marcelo Vidad — Field Study Journal

An original, four-page teaching-journal website created for Angel Marcelo Vidad, a BTVTED student majoring in Computer Hardware Servicing at Mariano Marcos State University, College of Teacher Education.

## Design and navigation

This redesign deliberately breaks from the earlier typical tech portfolio layouts:

- A book-like home cover with two facing pages, foreword, and table of contents
- Distinct parchment and burgundy editorial design, Libre Baskerville and Nunito Sans fonts
- Field Study and Teaching Work presented as readable academic journal entries with manuscript margins and personal reflections
- Document Archive formatted as a bibliography-style index, with searchable and filterable original file links
- Responsive mobile layout with readable typography and no photo assets

## Pages

- `index.html` — cover, introduction, table of contents, and closing reflection
- `fieldwork.html` — expanded INCAT and MMSU Laboratory High School Field Study entries
- `teaching.html` — three teaching-material records with detailed descriptions
- `documents.html` — index of 27 original submitted files
- `script.js` — preserved source-linked document data and archive search
- `styles.css` — original journal visual design

All 27 original Google Drive file identifiers are retained. No photographs or image assets are loaded; the legacy `assets/` folder remains unused.
